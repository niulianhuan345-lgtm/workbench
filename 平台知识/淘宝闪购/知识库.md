## 一、战略定位

### 阿里即时零售核心载体
- **前身**：饿了么 + 淘宝小时达整合
- **品牌升级**：2025年统一为「淘宝闪购」
- **战略级别**：2026年提升为阿里一级战略
- **核心口号**：「三年不担心亏损」
- **终极目标**：2028财年交易规模过万亿，2029财年整体盈利

### 战略意义
- 即时零售作为大消费战略的关键一环
- 淘宝闪购 = 阿里的「近场触点」
- 将传统电商用户引流至即时零售场景
- AI + 即时零售双线作战

## 三、核心竞争策略

### 3.1 生态协同（最大差异化优势）
```
淘宝（电商流量）
  + 饿了么（即时配送网络）
  + 高德（LBS 流量）
  + 支付宝（支付+金融）
  + 菜鸟（物流基建）
  = 全域即时零售生态
```

**协同优势**：
- 不用分两套团队运营，一套体系覆盖多端
- 多端流量入口聚合
- 用户数据打通，画像更精准
- 商家只需一次接入，全渠道分发

### 3.2 补贴策略
- 强力补贴快速拉升用户规模和订单量
- 2025年超 500 亿补贴预算
- 差异化补贴：新客首单、老客复购、品类定向
- 2026年核心任务：收窄单均亏损

### 3.3 品牌统一
- 从「饿了么」「淘宝小时达」统一为「淘宝闪购」
- 建立统一的品牌认知
- 承载阿里即时零售的核心品牌资产

### 3.4 即时配送能力
- 强化即时配送网络
- 与美团配送时效对标
- 履约成本优化：当前单均高 0.4 元，缩窄中

## 四、运营体系

### 4.1 商家运营
| 角色 | 职责 |
|------|------|
| 品牌商家运营 | 头部品牌入驻、联合营销、专属资源 |
| 供给运营 | 品类丰富度、库存管理、区域覆盖 |
| 活动运营 | 大促节奏、品类日、新店扶持 |
| 数据运营 | 商家诊断、增长建议、竞品分析 |

### 4.2 用户运营
- **新客获取**：首单立减、新人专享价、多端引流
- **老客留存**：会员体系、签到打卡、积分兑换
- **沉睡唤醒**：Push 推送、优惠券到期提醒
- **场景运营**：早餐/午餐/下午茶/晚餐/夜宵全时段覆盖

### 4.3 内容运营
- 淘宝直播 + 短视频内容联动
- 达人探店/测评内容
- 大促节点内容营销（双11、618、超级88）

### 4.4 品类策略
- **核心品类**：餐饮外卖（基本盘）
- **增长品类**：生鲜、超市便利、3C 数码
- **潜力品类**：医药健康、美妆个护、宠物

## 五、投放策略体系

### 5.1 平台内投放（淘系生态）
| 投放工具 | 用途 | 适用场景 |
|----------|------|----------|
| 万相台无界 | 全域智能投放 | 全场景覆盖 |
| 直通车 | 搜索关键词投放 | 用户主动搜索场景 |
| 引力魔方 | 推荐流量投放 | 首页猜你喜欢等 |
| 达摩盘 | 人群定向/精细化 | 高价值人群圈选 |
| 淘宝联盟 | CPS 分销 | 站外引流 |

### 5.2 投放场景（与 AIONE 6大场景对齐）
1. **关键词投放**：用户搜索「咖啡外卖」「早餐」等意图词
2. **精准人群**：LBS + 消费行为 + 品类偏好定向
3. **消费者运营**：新客/老客/沉睡用户分层投放
4. **货品运营**：爆品助推、新品冷启动、清仓促销
5. **内容营销**：直播切片、短视频投流
6. **店铺运营**：品牌专区、店铺首页、会员页

### 5.3 即时零售投放特殊性
| 特性 | 策略应对 |
|------|----------|
| 时效性强 | 分时段出价（高峰加价30-50%） |
| 地域性强 | LBS 圈选（3km/5km 配送半径） |
| 品类季节性强 | 夏季饮品、冬季火锅差异化投放 |
| 库存实时性 | 结合库存状态控制投放开关 |
| 天气敏感 | 雨天/高温天气自动加投 |

### 5.4 效率评估指标
| 指标 | 计算方式 | 健康基准 |
|------|----------|----------|
| 广告费比 | 花费增量 / 广告订单增量 | 越低越好 |
| ROI | 广告带来 GMV / 广告花费 | >3 为佳 |
| 蚕食率 | 自然订单被广告侵占比例 | <30% 为健康 |
| CPA | 广告花费 / 转化数 | 按品类设目标 |
| 新客占比 | 新客订单 / 总广告订单 | 看增长阶段 |

## 六、与美团/京东的差异对比

| 维度 | 淘宝闪购 | 美团 | 京东外卖 |
|------|----------|------|----------|
| 流量来源 | 电商+LBS+支付多端 | 外卖+到店 | 电商+物流 |
| 核心优势 | 生态协同 | 配送网络+商户覆盖 | 物流+品质 |
| 商家策略 | 平台补贴驱动 | 强商户关系 | 免佣金吸引 |
| 用户心智 | 「即时零售」 | 「外卖」 | 「品质外卖」 |
| 盈利状态 | 大幅亏损 | 亏损收窄 | 高额亏损 |
| 战略耐心 | 三年不担心亏损 | 追求盈亏平衡 | 战略性投入 |

## 七、2026年战略重点

1. **收窄单均亏损**：单均亏损收窄是核心 KPI
2. **履约成本优化**：缩小与美团的 0.4 元差距
3. **品牌升级深化**：统一认知，强化用户心智
4. **品类拓展**：从餐饮向全品类即时零售进化
5. **商家赋能**：数据工具 + 投放工具 + 经营诊断
6. **技术创新**：AI 选品、智能定价、路径优化
7. **下沉渗透**：三四线城市即时零售布局
