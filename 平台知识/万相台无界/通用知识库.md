## 一、产品总览

### 1.1 什么是万相台无界版

万相台无界版是阿里妈妈统一投放平台，整合了原有的**直通车、引力魔方、万相台**三大产品，提供一站式的广告投放管理。商家通过 one.alimama.com 登录使用。

**一句话：** 搜索+推荐+AI智能的统一投放工作台。

### 1.2 整合前身

| 原产品 | 整合后的场景 | 核心能力 |
|--------|------------|---------|
| 直通车 | 关键词推广 | 搜索关键词竞价，精准拦截搜索流量 |
| 引力魔方 | 人群推广 | 推荐信息流人群定向，拉新+竞争突破 |
| 万相台 | 货品全站推广 | AI 智能投放，付免一体，全生命周期运营 |

### 1.3 核心设计理念

- **付免一体：** 付费流量和免费流量统一运筹，追求全店 GMV 最大化
- **AI 驱动：** 算法自动选品、出价、分配预算，降低人工操作成本
- **全生命周期：** 覆盖新品冷启→成长品放量→爆品维稳的完整链路
- **一站式：** 一个平台管理所有投放，统一报表、统一账户

## 二、6 大投放场景

### 2.1 关键词推广（原直通车）

**定位：** 搜索场域的精准拦截广告

**核心机制：**

| 维度 | 说明 |
|------|------|
| 投放位置 | 淘宝搜索结果页（PC+无线） |
| 计费方式 | **CPC 按点击付费**，无点击不扣费 |
| 核心逻辑 | 买家搜索关键词 → 触发竞价 → 按质量分×出价排序 → 展示广告 |
| 适用目标 | 精准拦截搜索意图，守住成交心智 |

**关键词类型体系：**

| 类型 | 定义 | 特征 | 使用场景 |
|------|------|------|---------|
| **品牌词** | 含自身品牌名的词，如"Nike跑鞋" | 转化高、CPC低、必防守 | 品牌保护，防止竞品截流 |
| **竞品词** | 含竞品品牌名的词 | 截流竞品流量、CPC偏高 | 进攻型，抢竞品用户 |
| **类目词** | 品类通用词，如"跑鞋""连衣裙" | 流量大、竞争激烈 | 拉新获客 |
| **长尾词** | 多词组合精准搜索 | 流量小但精准、转化高 | 精准收割 |
| **核心词** | 产品最核心的1-2词 | 流量与精准度平衡点 | 日常稳定投放 |
| **人群词** | 描述目标人群特征，如"学生党" | 泛流量 | 配合人群定向使用 |

**4 种匹配方式：**

| 匹配方式 | 说明 | 流量精准度 |
|---------|------|:---:|
| **广泛匹配** | 同义词、变体、相关词均可触发 | 最宽 |
| **精准匹配** | 搜索词与关键词完全一致或紧密变体 | 最严 |
| **短语匹配** | 搜索词包含关键词，前后可加词 | 居中 |
| **中心词匹配** | 按关键词的核心词根匹配（新功能） | 语义级 |

**出价机制：**
- **手动出价：** 广告主设定 CPC 上限
- **系统出价（OCPC）：** 系统根据转化目标自动调整出价
- **分时折扣：** 按小时设置出价折扣比例
- **人群溢价：** 对特定人群在基础出价上加价
- **资源位溢价：** 对不同资源位设置溢价比例

### 2.2 人群推广（原引力魔方）

**定位：** 推荐信息流的人群拉新+竞争突破

**核心机制：**

| 维度 | 说明 |
|------|------|
| 投放位置 | 首页猜你喜欢、购中/购后推荐、微详情等淘系信息流 |
| 计费方式 | CPM（千次展现）/ CPC（点击） |
| 核心逻辑 | 人群定向→信息流推荐位展示→吸引点击进店 |

**三大核心价值：**

**① 极致人群拉新**
- 新客范围：7/15/30/90/180/365 天未购买人群
- 触达频次：可控制近 7/15/30 天触达频率
- 拉新范围：全域拉新 / 同类目拉新 / 跨类目拉新
- 新客 ROI：独立的新客消耗/成交/ROI 指标

**② 实现竞争突破**

| 竞争类型 | 能力 | 说明 |
|---------|------|------|
| 竞争宝贝-人群提渗透 | 定向竞品兴趣人群 | 智能/自定义竞品，触达其兴趣消费者 |
| 竞争宝贝-同屏抢焦点 | 定向竞品附近流量位 | 在竞品流量位附近展示 |
| 竞争店铺 | 定向竞店兴趣人群 | 智能/自定义竞店，加深关联匹配度 |

**③ 聚焦信息流流量**
- 核心资源位：首猜、购后（消耗占比 70%+）
- 支持资源位溢价（手动出价模式）
- 搜索流量开关可控

---

### 2.3 货品全站推广（万相台升级版）

**定位：** AI 驱动的付免一体全店增长引擎

**核心机制：**

| 维度 | 说明 |
|------|------|
| 投放范围 | 淘系全域（搜索+推荐+互动场景） |
| 计费方式 | 按点击扣费，控投产比模式 |
| 核心逻辑 | 设定目标 ROI → AI 自动选品+出价+分配 → 交付 ROI |

**全生命周期货品运营：**

```
新品 ──→ 成长品 ──→ 爆品
 │          │         │
 ▼          ▼         ▼
破百单更快  GMV增长   销量更稳定
 +35.6%     +30%      排名卡位
```

**关键能力：**

| 能力 | 说明 | 效果 |
|------|------|:---:|
| **AI效果智达** | AI生成式出价模型，优化ROI达成 | ROI达标率+10% |
| **全店模式** | 一键托管，AI自动选品+出价+预算分配 | 全店GMV+31% |
| **一键起量** | 成本可控下提升跑量 | 放量+40%，GMV+20% |
| **多目标出价** | ROI基础+加购/成交增量目标 | GMV+15% |
| **平台推荐品** | AI挖掘最有潜力的商品 | GMV环比+35.6% |

**三种模式：**
- **单品模式：** 手动选品，设置 ROI 和日预算
- **全店模式：** AI 自动选品，一个计划覆盖全店
- **分组投放（全店模式新能力）：** 多个计划组，每组独立设置出价/预算/商品

**常见QA摘要：**
- 与其他场景互斥：同一商品开启全站推广后不能建其他计划
- 扣费：末次点击归因，按转化时间统计
- 资源位：全域投放，核心搜索+推荐，不可屏蔽资源位
- 预算：建议初始设为 5-20 个转化成本，稳定后设不限

## 三、账户与计划体系

### 3.1 账户层级

```
账户
 ├── 账户预算（总日限额）
 ├── 计划组（万相台无界特有组织方式）
 │    ├── 计划 1
 │    │    ├── 单元 1
 │    │    │    ├── 关键词
 │    │    │    ├── 人群定向
 │    │    │    └── 创意
 │    │    └── 单元 2
 │    └── 计划 2
 └── 虚拟计划组（系统自动归类）
```

### 3.2 计划类型

| 类型 | 说明 |
|------|------|
| **标准计划** | 手动管理关键词、出价、人群 |
| **智能计划** | 系统自动优化出价和关键词 |
| **全店模式计划** | 全站推广的 AI 自动托管计划 |

### 3.3 计划组

计划组是万相台无界的组织创新：
- 将多个计划归入一个组，便于统一管理预算和分析
- 计划组可有独立预算上限
- 虚拟计划组由系统自动按场景归类

### 3.4 账户计划数容量

- 平台根据历史消耗和投放规模自动升降档
- 消耗达标+商品数多 → 自动提升计划数上限

## 四、出价与计费体系

### 4.1 计费方式

| 方式 | 英文 | 说明 | 使用场景 |
|------|------|------|---------|
| 按点击付费 | CPC | 每次点击扣费 | 关键词推广、人群推广 |
| 按千次展现 | CPM | 千次展现扣费 | 人群推广（部分） |
| 按成交付费 | CPS | 成交后按佣金扣费 | 小店成交宝、淘宝客 |
| 智能出价 | OCPC/OCPM | 系统自动优化出价 | 全站推广、智能计划 |

### 4.2 出价策略

| 策略 | 说明 |
|------|------|
| **最大化拿量** | 在预算内尽可能获取更多转化 |
| **控投产比** | 设定目标 ROI，系统自动出价达成 |
| **手动出价** | 广告主设定 CPC 上限 |

### 4.3 扣费逻辑

- **末次点击归因：** 按最后点击的广告计入转化
- **按转化时间统计：** 效果数据按转化发生时间归因
- **实际扣费 ≤ 出价：** 竞价机制决定实际扣费
- **质量分影响：** 质量分越高，实际 CPC 越低

### 4.4 最低出价

- 平台根据**商圈/类目的竞争程度**设定的出价下限
- 这是**平台结构性约束**，不代表门店/商品质量
- 如果商圈竞争激烈，最低出价会升高
- 在分析时，最低出价不应作为效率评分扣分项

### 4.5 预算相关

| 概念 | 说明 |
|------|------|
| 账户日预算 | 整个广告账户的日花费上限 |
| 计划日预算 | 单个计划的日花费上限 |
| 撞预算 | 计划预算耗尽后提前下线 |
| 预算分配策略 | 多计划间算法自动分配预算 |

## 十、关键认知

1. **计划是万相台无界的管理核心单元，不是商品。** 一个计划包含关键词+人群+创意+出价+预算。

2. **全站推广改变了投放逻辑。** 传统是"选词→出价→看效果"，全站推广是"设ROI→AI搞定→看GMV"。

3. **最低出价是结构性约束，不是效率指标。** 商圈竞争激烈→最低出价高，不等于该门店投放能力差。

4. **蚕食 vs 增量是评估广告真实价值的核心。** 广告订单中有一部分"不投也会成交"，需要分离评估。

5. **子账号权限影响数据完整性和分析结论。** 拿不到全量数据时，分析结论需要标注数据范围。

6. **618/双11 期间平台规则会临时调整。** 大促期间各场景有降级/升级通知，需要关注。

7. **投放效果有延迟。** 前一天数据次日中午前更新，实时分析需考虑数据延迟。

8. **多场景组合投放效果 > 单一场景。** 跨场景分析和优化是提升投放效率的核心手段。
