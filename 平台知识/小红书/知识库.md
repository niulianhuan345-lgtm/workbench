## 聚光平台概述

**聚光平台**（ad.xiaohongshu.com）是小红书营销的一站式广告投放平台，内部代号 **Aurora**（极光）。

### 平台定位
满足广告主以 **5 大营销目标** 为导向的多样化投放诉求：

| 目标 | 说明 |
|------|------|
| 🪴 产品种草 | 通过内容营销建立品牌/产品认知和好感 |
| 🛒 商品销量 | 直接驱动电商转化和销售 |
| 📋 客资收集 | 获取潜在客户线索（表单/私信） |
| 📺 直播推广 | 推广直播间，提升直播观看和互动 |
| 🏁 抢占赛道 | 在竞争激烈的品类中抢占市场份额（"赛马"机制） |

### 核心能力
- **打通搜索+浏览双场景**：同时覆盖用户主动搜索和信息流浏览两大决策场景
- **SPU 颗粒度定向**：以产品（SPU）为最小粒度的精准定向和智能投放
- **信息流广告 + 搜索广告**双引擎

## 结构化投放（🆕 2026-07-03 发现）

### 产品概述
- **产品名称**: 结构化投放
- **定位**: 替换原「搜索省心投」的自动化投放产品
- **核心理念**: 客户前置输入 SPU，以 SPU 为维度进行模型预估，系统自动+实时调配预算、出价、词和物料的匹配逻辑
- **本质**: 从「计划粒度」升级为「SPU/业务点粒度」的高维投放方式

### 产品价值
- **提升跑量**: 同一 SPU 聚合投放，提升标的跑量能力
- **减轻基建压力**: 一个标的一个计划，不需要大量计划堆积
- **精准人群预估**: 信息聚拢后模型预估更精准
- **实测效果**: 10家客户测试中，跑量提升15%+，计费比下降24%，空耗比例下降73%

### 适配场景
- 营销诉求: 客资收集（其他场景待扩展）
- 推广类型: 搜索推广
- 搭建方式: 自动化投放
- 转化目标: 私信开口/私信留资
