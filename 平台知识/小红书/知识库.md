## 一、平台概览

小红书商业化平台，包含聚光（效果广告）和蒲公英（达人合作）两大体系。

### 官方定位（来源：页面 meta）

- **聚光平台**：一站式广告投放平台，满足「产品种草、商品销量、客资收集、直播推广、抢占赛道」5 大营销目标。打通搜索 + 浏览两大关键决策场景，支持 SPU 级精准定向和智能投放。
- **蒲公英平台**：内容种草与直播合作官方平台，「好产品种收第一站」。

### 核心产品矩阵

| 产品 | 定位 | 适用场景 | 计费方式 |
|------|------|---------|---------|
| 聚光平台 | 效果广告投放 | 笔记/商品/直播/线索推广 | CPC/CPM/CPA |
| 蒲公英 | 达人内容合作 | 品牌种草+直播带货 | 一口价/效果付费 |
| 品牌广告 | 品牌曝光 | 开屏/信息流 | CPM |
| 薯条 | 内容加热 | 笔记推广 | CPM |

> 访问地址：pgy.xiaohongshu.com | 前端包名：pgy-pc 1.20.0 | 公式版本：4.3.9

### 达人合作模式

| 模式 | 说明 |
|------|------|
| 招募模式 | 发布需求，达人主动报名，适合规模化合作 |
| 邀约模式 | 直接联系指定达人，1v1 深度合作 |
| 一口价 | 固定价格合作，按笔记/视频/直播场次报价 |
| 效果付费 | 按实际效果（阅读量/互动量/GMV）结算 |
| 直播合作 | 达人直播带货，可挂商品链接 |

### 达人筛选维度

- 粉丝量级、粉丝画像（年龄/地域/兴趣）
- 笔记互动率（点赞/收藏/评论/分享）
- 内容风格/领域匹配度
- 商业笔记历史表现（CPE/CPM 参考）
- 粉丝增长趋势与健康度
- 直播数据（场均观看、场均GMV）
- 历史合作品牌与报价

### 合作全流程

| 阶段 | 关键动作 |
|------|---------|
| 需求发布 | 明确预算、数量、内容方向、发布时间 |
| 达人筛选 | 平台数据辅助筛选，支持多维对比 |
| 合作确认 | 确定合作模式、内容要求、交付时间 |
| 内容审核 | 笔记/视频内容预览和修改 |
| 发布投放 | 达人发布，配合聚光投流加热 |
| 效果复盘 | 查看种草值、互动数据、转化归因 |

### 蒲公英 × 聚光联动

- 蒲公英达人笔记可一键同步至聚光平台进行付费加热
- 支持对蒲公英笔记进行信息流/搜索广告投放
- 种草值数据打通，从内容种草到效果转化全链路追踪
