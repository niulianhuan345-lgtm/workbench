## 一、平台概览

京准通是京东旗下数字营销平台，服务京东商家的一站式广告投放。

### 核心产品矩阵

| 产品 | 定位 | 适用场景 | 计费方式 |
|------|------|---------|---------|
| 京东快车 | 搜索广告 | 搜索结果页 | CPC |
| 购物触点 | 推荐广告 | 推荐/信息流 | CPM/CPC |
| 京东海投 | 智能投放 | 全店自动化 | CPC |
| 京东展位 | 品牌展示 | 首页/频道页 | CPM |
| 京挑客 | CPS效果 | 站外推广 | CPS |
| 直投广告 | 站外DSP | 腾讯/头条等 | 多种 |
| DMP(数坊) | 人群管理 | 人群圈选 | — |
| 京速推 | 智能推广 | 简单高效的自动化推广 | CPC |
| 全站营销 | 全场景自动化 | 搜索+推荐+内容全覆盖 | 多种 |
| 交互推广 | 互动广告 | 互动式广告（含直播/短视频） | 多种 |

- 展现量、点击量、点击率(CTR)

- 投产比(ROI)、转化率
- 收藏加购量

### 差异化特点

- SPU/SKU级别出价
- 无线/PC分开出价
- 推荐出价工具
- 抢排名工具

## 六、智能出价与优化策略

### 出价方式

| 方式 | 说明 | 适用场景 |
|------|------|---------|
| 手动出价 | 广告主自行设定出价 | 精细化控制 |
| 系统出价(OCPX) | 系统基于转化目标自动出价 | 稳定成本、提升转化 |
| 最大化转化量 | 在预算内最大化转化数 | 追求量级 |
| 目标ROI | 设定目标投产比，系统自动优化 | 稳定ROI |
| 成本控制(CPP) | 控制单次转化成本上限 | 控制获客成本 |

### 人群定向能力

| 定向类型 | 说明 |
|---------|------|
| 基础定向 | 地域、性别、年龄、设备等 |
| 行为定向 | 浏览/搜索/加购/购买行为 |
| 兴趣定向 | 类目/品牌/商品兴趣标签 |
| DMP人群包 | 上传人群包、规则圈选、模型预测 |
| 智能扩量 | 基于种子人群自动扩展相似人群 |
| RTA(实时竞价) | 广告主侧实时决策是否竞价 |
