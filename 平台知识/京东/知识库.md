## 一、平台概览

京准通是京东旗下数字营销平台，服务京东商家的一站式广告投放。

### 核心产品矩阵

| 产品 | 定位 | 适用场景 | 计费方式 |
|------|------|---------|---------|
| 京东快车 | 搜索广告 | 搜索结果页 | CPC |
| 购物触点 | 推荐广告 | 推荐/信息流 | CPM/CPC |
| 京东海投 | 智能投放 | 全店自动化 | CPC |
| 京东展位 | 品牌展示 | 首页/频道页 | CPM |

## 二、京东快车

| 特性 | 说明 |
|------|------|
| 广告位 | 搜索结果页+商品详情页+分类页 |
| 推广单元 | 计划→单元→关键词/商品 |
| 匹配方式 | 切词匹配/短语匹配/精确匹配 |
| 质量分 | 预估点击率+相关性+落地页体验 |
| 出价 | 关键词出价+人群溢价+时间折扣 |

### 关键指标

- 展现量、点击量、点击率(CTR)
- 总花费、平均点击成本(CPC)
- 直接订单/间接订单、订单金额
- 投产比(ROI)、转化率
- 收藏加购量

### 差异化特点

- SPU/SKU级别出价
- 无线/PC分开出价
- 品牌追击（竞品词投放）— 🆕 2026-06新增功能
- 智能匹配+手动出价双模式

## 五、DMP（数坊）

| 特性 | 说明 |
|------|------|
| 产品名 | 京东数坊（DMP） |
| 功能 | 人群圈选、洞察分析、人群扩展 |
| 标签维度 | 用户属性/行为/兴趣/购买力/生命周期 |
| 应用 | 所有京准通产品可用DMP人群包投放 |
| 分析工具 | RFM分析、搜索词分析、购买分析 |

### 关键人群定义（AIONE 可直接使用）
- **新客**：365天内无店铺购买记录的用户
- **老客**：365天内有店铺购买记录的用户
- **潜客**：有浏览/搜索/加购行为但未购买的用户
- **流失预警**：180-365天前购买，之后无行为的用户
