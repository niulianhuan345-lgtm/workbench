## 一、唯品会广告投放平台 — 大有可唯（e.vip.com）

### 平台概述
- **名称**: 大有可唯 / 唯品会营销平台
- **URL**: https://e.vip.com
- **管理后台**: https://e.vip.com/upgrade.html
- **登录**: https://passport.vip.com/login?whereFrom=vipotd
- **描述**: 唯品会旗下数字营销平台，依托唯品会电商平台大数据优势，为广告主提供大有可唯智能营销一体化解决方案

### 广告资源体系

| 资源类型 | 说明 |
|----------|------|
| **站内优选** | 唯品会站内广告位资源 |
| **移动精选** | 站外移动端精选流量资源 |
| **腾讯广告** | 对接腾讯广告（微信/QQ/腾讯视频等）投放 |
| **百度推广** | 百度搜索/信息流推广 |
| **唯享客** | 微商社交长尾资源（CPS社交分销） |

### 核心功能

1. **全网资源整合与智能投放**
   - 整合站内+站外资源一站式投放
   - 支持 oCPC/oCPA 智能出价，按转化效果优化，自动调价控制成本

2. **全链路数据资产管理**
   - 集成唯品会核心电商用户行为及交易数据
   - 支持第三方监测同步数据
   - 对接腾讯广告/百度推广 DMP 数据
   - 构建广告主私有数据银行
   - 全链路追踪：曝光 → 点击 → 花费 → 唤起APP → 到站转化销售

3. **动态创意生成（唯妙创意）**
   - 基于唯品会智能推荐算法，匹配用户感兴趣的商品
   - 创意模板组合 + 实时推送 = 千人千面动态商品广告
   - 新品自动推荐爆款商品，自适应生成多尺寸素材
   - 支持商品图片合成视频

4. **精准人群定向**
   - 利用唯品会电商数据 + 腾讯广告 DMP
   - 精准定位潜在兴趣人群，降低获客成本

5. **智能出价（无人驾驶投放）**
   - 设置预算和目标即可一键投放
   - 智能出价和调价算法自动优化效果

## 四、广告产品类型（OTD系统）

- **OTD**: 唯品会广告投放系统名称
- **广告形式**: 品牌触达、精准曝光、社交电商、内容种草
- **出价方式**: oCPC（按点击优化转化）、oCPA（按转化出价）、CPM（竞价广告）
- **投放流程**: 广告标题(6-18字) → 描述(2-20字) → 子标题(2-20字) → 按钮文字 → 投放
- **素材格式**: 支持静态图片、动态视频等多种格式
