1. 什么是 Hermes Agent

一句话：Hermes Agent 是一个能帮你写代码、查数据、做分析、发消息的 AI 助手。它可以跑在终端里，也可以接入飞书/钉钉/微信/Telegram 等聊天平台。 核心特点：

- 🧠 有记忆：会记住你的偏好、习惯，下次不用重复说 - 🔧 有工具：能读写文件、搜网页、查数据库、跑 Python 脚本 - 🌐 多平台：同一个 AI 可以同时在飞书、钉钉、终端里使用 - 📅 定时任务：可以设置每天早上自动发日报、自动拉数据

- 🏠 离线可用：可以不依赖任何外部 API，用本地模型运行

3. 安装 Hermes（2 分钟）

3.1 一条命令安装

打开终端（Terminal.app 或任何终端），复制粘贴这行：

curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

你会看到这样的输出：

🚀 Installing Hermes Agent...

Cloning into '/Users/xxx/.hermes/hermes-agent'... Creating virtual environment... Installing dependencies... ✅ Hermes Agent installed!

3.2 验证安装

hermes --version

应该显示类似 Hermes Agent v2.x.x。

3.3 如果报错 "command not found"

把下面这行加到 ~/.zshrc（如果用了 bash 则是 ~/.bashrc）：

export PATH="$HOME/.hermes/hermes-agent/venv/bin:$PATH"

然后执行 source ~/.zshrc 再试。

Windows 用户：用 WSL2 安装，不要在 PowerShell 里直接装。WSL2 安装指南：https://learn.microsoft.com/zh-cn/windows/wsl/install

4. 配置 AI 模型（10 分钟）

4.1 使用设置向导（推荐新手）

hermes setup

会出现一个交互式菜单，按箭头键选择：

1. 选择你的模型提供商（DeepSeek、Anthropic 等） 2. 输入你的 API Key

3. 选择默认模型（DeepSeek 选 deepseek-chat）

4.2 手动配置（老手 / 需要精确控制）

第一步：把 API Key 写入 .env 文件 
# 编辑密钥文件

nano ~/.hermes/.env

写入内容（替换成你的真实 Key）：

# DeepSeek（如果你用 DeepSeek）

DEEPSEEK_API_KEY=sk-你的密钥



或者 Anthropic（如果你用 Claude）


ANTHROPIC_API_KEY=sk-ant-你的密钥



或者阿里百炼（如果你用 Qwen）


DASHSCOPE_API_KEY=sk-你的密钥

保存退出（nano 里按 Ctrl+O 再 Ctrl+X）。

第二步：编辑配置文件 
hermes config edit

会打开 ~/.hermes/config.yaml。找到 model: 段，改成：

# 示例：用 DeepSeek

model:   provider: deepseek   default: deepseek-chat


# 示例：用 Claude

model:   provider: anthropic   default: claude-sonnet-4
第三步：验证配置 
hermes config check

应该显示所有检查都 ✓ 通过。

4.3 用自定义 OpenAI 兼容 API

如果你想用 OpenRouter、OneAPI 或任何 OpenAI 格式的代理：

custom_providers:

  - name: my-api     base_url: https://你的API地址/v1


    key_env: CUSTOM_API_KEY



model:   provider: my-api   default: 模型名称

然后在 .env 里加：CUSTOM_API_KEY=你的密钥

5. 连接飞书/钉钉（20 分钟）

5.1 飞书配置

第一步：创建飞书应用

1. 打开 https://open.feishu.cn 2. 进入「开发者后台」→「创建企业自建应用」

3. 应用名称随意（比如「Hermes 助手」）

第二步：添加机器人能力

在应用页面左侧点击「添加应用能力」→ 选择「机器人」。

第三步：配置权限

左侧「权限管理」→ 搜索并开通以下权限：

权限用途
im:message收发消息
im:message.p2p_msg:readonly读取私聊消息
im:message.group_msg:readonly读取群聊消息
im:message:send_as_bot发送消息
im:resource上传图片/文件

点「批量开通」→ 确认。

第四步：获取凭证

左侧「凭证与基础信息」→ 复制：

- App ID（以 cli_ 开头）

- App Secret（一串随机字符）

第五步：写入 Hermes 配置 
# 编辑 .env

nano ~/.hermes/.env

添加：

FEISHU_APP_ID=cli_你的AppID

FEISHU_APP_SECRET=你的AppSecret


# 编辑配置

hermes config edit

找到 gateway: 段，确保 feishu 已启用：

gateway:

  platforms:     feishu:       enabled: true
第六步：发布应用

回到飞书开发者后台 → 右上角「创建版本」→ 填写版本号（如 1.0.0）→「保存」→「申请线上发布」。

第七步：把机器人加到群里

在飞书里创建一个群 → 群设置 → 添加机器人 → 搜索你的应用名称 → 添加。

5.2 钉钉配置

第一步：创建钉钉应用

1. 打开 https://open-dev.dingtalk.com 2. 登录 →「应用开发」→「钉钉应用」→「创建应用」

3. 选择「企业应用」→ 填写名称

第二步：配置机器人

左侧「机器人与消息推送」→ 开启「机器人配置」。

第三步：配置权限

左侧「权限管理」→ 搜索并开通：

权限用途
企业内机器人发送消息发消息
根据手机号姓名获取成员信息获取用户信息
第四步：获取凭证

「凭证与基础信息」→ 复制 AppKey 和 AppSecret。

第五步：写入 Hermes 配置 
nano ~/.hermes/.env

添加：

DINGTALK_APP_KEY=你的AppKey

DINGTALK_CLIENT_SECRET=你的AppSecret DINGTALK_CLIENT_ID=你的AppKey


# hermes config edit

gateway:   platforms:     dingtalk:       enabled: true
第六步：发布应用

点击「版本管理与发布」→「创建新版本」→ 发布。

第七步：把机器人加到群里

钉钉群 → 群设置 → 智能群助手 → 添加机器人 → 搜索你的应用 → 添加。

5.3 群聊策略（重要）

群聊里要不要每次都 @ 机器人才理你？

在 config.yaml 里设置：

gateway:

  platforms:     feishu:       group_policy: open    # open = 所有消息都回复，mention = 只有 @机器人 才回复
💡 如果你想让机器人"监听"群里的所有消息（不 @ 也回复），设 open。
如果只想在 @ 的时候才干活，设 mention。

6.1 先测试终端模式

hermes chat -q "你好，请用中文回复，告诉我你是谁"

如果正常收到回复，说明模型配置成功。

如果日志显示 platform dingtalk connected successfully 或 platform feishu connected successfully，说明连接成功。

8. 常见问题

❓ 提示 "No models provided"

.env 里没写 API Key，或者 Key 写错了。 解决：nano ~/.hermes/.env 检查 Key 是否完整。

❓ 飞书机器人不回复

检查清单： 1. ✅ 应用已发布（不是草稿状态） 2. ✅ 机器人已加入群聊 3. ✅ 权限已开通（特别是 im:message） 4. ✅ ~/.hermes/.env 里 FEISHU_APP_ID 和 FEISHU_APP_SECRET 正确

5. ✅ Gateway 已启动：hermes gateway status

❓ 钉钉机器人不回复

检查清单： 1. ✅ 应用已发布（版本管理与发布 → 已发布） 2. ✅ AppKey 和 AppSecret 正确 3. ✅ 机器人权限已开通

4. ✅ 查看日志：grep -i dingtalk ~/.hermes/logs/gateway.log | tail -20

❓ "command not found: hermes"

PATH 没加。参考第 3.3 节。

❓ Gateway 退出后机器人就断了

需要把 Gateway 安装为系统服务：

hermes gateway install   # 安装 launchd（macOS）或 systemd（Linux）

hermes gateway start     # 启动

这样即使关闭终端，机器人也会一直在后台运行。

❓ 回复太慢 / 中文回答被截断

- 换更快的模型：hermes model → 选 DeepSeek - 缩短上下文：终端里用 /new 开始新对话

- 模型问题：试试 deepseek-chat（比 deepseek-reasoner 快很多）

❓ 想停止某个正在运行的任务

飞书/钉钉里直接说"停止"或"取消"，或在终端按 Ctrl+C。

9. 进阶：多配置/定时任务

9.1 创建多套配置

如果你有多个项目，需要不同的模型或工具：

# 创建新配置（profile）

hermes profile create work    # 工作用


hermes profile create home    # 家里用



切换到某个 profile


hermes profile use work



查看所有 profile


hermes profile list

每个 profile 有独立的 .env、config.yaml、技能和记忆。

9.2 设置定时任务

每天早上 9 点自动发日报：

hermes cron create "0 9   *" --prompt "帮我拉取昨天的数据并生成日报，发送到当前群"

每 1 小时执行一次：

hermes cron create "every 1h" --prompt "检查服务器状态"

管理定时任务：

hermes cron list       # 查看所有

hermes cron pause  # 暂停 hermes cron run    # 立即执行一次 hermes cron remove  # 删除

9.3 添加更多能力（Skills）

Hermes 有技能商店，可以安装各种技能：

# 浏览

hermes skills browse



搜索


hermes skills search 数据分析



安装


hermes skills install <技能名>
